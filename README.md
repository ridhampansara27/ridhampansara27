## 🚀 Featured Platform — CloudOps Insight

**[CloudOps Insight](https://cloudopsinsight.tech)** is my flagship cloud engineering project: a multi-tenant CloudOps and FinOps platform for AWS resource visibility, health monitoring, cost insight, incidents and recommendations.

- **Cloud-native application:** React · FastAPI · PostgreSQL · Redis · Celery
- **Platform:** Kubernetes on OCI OKE · Helm · Argo CD
- **Infrastructure:** Terraform-managed networking, cluster, storage and recovery resources
- **Cloud integration:** AWS STS cross-account access · CloudWatch · Cost Explorer
- **Delivery & security:** GitHub Actions · image scanning · controlled GitOps promotion · RBAC
